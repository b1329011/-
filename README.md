# 不揪喔

「不揪喔」是一個以運動與麻將揪團為核心的資料庫專案，目標是協助使用者快速找到附近場地、即時媒合缺人的球局或牌局，並整合天氣、空氣品質、場地租借與費用分攤資訊，降低臨時揪團失敗的機率。

## 系統目標

本系統主要解決以下問題：

- 場地難找，且不容易即時掌握場地是否有空位。
- 臨時缺球友或牌友，導致活動取消。
- 天氣與空氣品質不容易即時判斷，戶外活動可能遇到下雨或環境不佳。
- 主揪需要同時處理訂場地、收費、候補、取消與通知等流程。

系統預計服務範圍以北北桃為主，支援活動包含籃球、排球、羽毛球與麻將。

## 主要功能

### 一般使用者

- 在月曆上標記可參加的時間與所在地點。
- 依照年齡、程度、活動類型與地區篩選可加入的隊伍。
- 查看系統推薦的隊伍，包含目前人數、目標人數、場地費與平均分攤金額。
- 加入活動、加入候補，或自行建立房間擔任主揪。
- 主揪可設定活動時間、地點、場地費、取消期限與是否需要訂金。
- 付費場地可設定免費取消期限，超過期限後取消需依規則處理訂金。
- 免費場地需由主揪於活動前 30 分鐘確認現場有場，否則通知成員活動未成團。
- 依照天氣與空氣品質推薦室內或室外場地。
- 針對麻將顯示即時缺 1、缺 2、缺 3 狀態，而不是只使用月曆篩選。
- 若使用者未到場、未付款或行為不佳，被檢舉成立後會扣除信譽積分。
- 信譽積分低於門檻者會被加入黑名單，限制使用系統。

### 管理者

- 查詢已成團的房間與已租借的場地。
- 審核場地資料。
- 處理使用者檢舉與信譽積分扣分。
- 處理因天氣、場地臨時關閉或不可抗力造成的活動異常。
- 即時與主揪或統籌人溝通。
- 可將即將結束但尚未成團的隊伍依照結束時間排序或置頂，提高曝光率。

## 推薦與判斷邏輯

系統會依據活動條件、使用者程度、場地類型與環境資料進行推薦。

使用者可依照以下條件篩選活動：

- 活動項目：籃球、排球、羽毛球、麻將。
- 活動程度：休閒、業餘、進階或職業等級。
- 活動地點：所在城市、行政區或附近場地。
- 場地類型：室內、室外或半戶外。
- 費用：免費場地或付費場地，並顯示平均分攤金額。

不適合遊玩指數的規劃公式：

```text
不適合遊玩指數 = 5 * 降雨機率 + AQI / 50
```

當天氣或空氣品質不佳時，系統會優先推薦室內場地。

## 資料來源

系統規劃整合以下 Open Data 或外部資料：

- 場地資料：全國運動場館資訊網  
  <https://iplay-um.sports.gov.tw/WebAPI/Index>
- 天氣資料：政府資料開放平台天氣資料  
  <https://data.gov.tw/dataset/9176>
- 空氣品質資料：政府資料開放平台空氣品質資料  
  <https://data.gov.tw/dataset/6380>

## 資料表設計

主要資料庫結構位於 `db/不揪喔.sql`，使用 MySQL / MariaDB 格式匯出。

目前資料表包含：

| 資料表 | 用途 |
| --- | --- |
| `users` | 使用者與管理者基本資料，包含姓名、年齡、電話、角色與信譽積分 |
| `user_sport_levels` | 使用者在不同運動項目的程度 |
| `sports` | 運動或活動項目 |
| `venues` | 場地資料，包含價格、開放時間、設施與場地類型 |
| `address` | 場地地址資訊 |
| `court` | 場館中的個別球場或場地 |
| `court_sports` | 場地可支援的運動項目 |
| `court_conflicts` | 場地之間的衝突或互斥關係 |
| `gamesmatches` | 揪團活動房間，包含主揪、場地、時間、人數、費用、狀態與天氣資訊 |
| `match_participants` | 活動參與者清單 |
| `reports` | 使用者檢舉紀錄 |
| `penalty_rules` | 扣分規則 |
| `blacklist` | 黑名單紀錄 |

## 技術規劃

- 前端形式：Web-based 系統。
- 後端形式：可搭配 PHP、Python 或 JavaScript 實作 API。
- 資料庫：MySQL / MariaDB。
- 外部資料：政府 Open Data 與全國運動場館資訊網。

## API 規劃

API 文件草稿位於 `web/api_format.md` 與 `web/api_format.html`。依照現有資料表，系統可規劃以下 API 模組：

- 使用者登入、個人資料與運動程度設定。
- 揪團房間查詢、建立、加入與退出。
- 主揪確認場地與活動成團狀態。
- 收藏活動或場地。
- 檢舉、扣分與黑名單管理。
- 場館、球場與可支援運動項目查詢。
