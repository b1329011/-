# 核心功能與邏輯

- 候補人數： 最大人數的30%
- ​能力分級： 暫定預設初學者，該在註冊時填寫。(需要再討論細分)
- 管理者介面： 後台具體需要哪些功能？增刪場地，系統公告發布，檢視統計數據（活躍人數，開團數……）
- 實際扣分規則
- 使用者：
  未出現 -20
  沒交錢 -15
  球品不好 -10
  不當言語 -10
  態度不佳 -10
  等級不符（有菜雞，炸魚的）
  騷擾與人身攻擊 -30
  肢體暴力 -60 //管理者收到通知，跟檢舉人聯繫
  直銷 -15
  40 ban forever
  50 回來65，+0.5day
  60給警告 不能創房間
- 主揪扣分規則：未出現、未回報場地、惡意抬價、沒預約場地、回報與實際場地不符(需設計)
- 不能重複檢舉

# ​時間與價格防呆

- ​開團時間校驗： 資料庫要新增是否營業，有無整修，以及營業時間。後端新增驗證邏輯，api要跟著修改回傳格式。
- ​價格控制： 直接放球場提供的表供使用者參考(資料庫需新增儲存圖片的欄位)

# 資料與架構
